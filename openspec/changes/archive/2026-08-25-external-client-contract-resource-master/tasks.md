# Tasks: TypeSpec-authoritative Resource Master external client contract

This is the ordered strict-TDD implementation plan for `external-client-contract-resource-master`. TypeSpec is the only authored external semantic authority. The trusted edge, generated runtime data, compatibility evidence, and documentation are downstream consumers. The plan selects the corrected design's local semantic emitter, deterministic manifest, manifest materializers, and opaque metadata values without selecting a transport, wire format, SDK, publication mechanism, productive identity provider, UI, or semantic-version policy.

Strict TDD applies to every work unit: RED establishes a reproducible failing test or fixture, GREEN adds the smallest behavior that makes that evidence pass, TRIANGULATE exercises adversarial and cross-layer cases, and REFACTOR removes duplication without changing the passing behavior. Generated artifacts are regenerated and byte-checked; they are never hand-authored as a second authority.
